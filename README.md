# 模拟证券 · 离线股票交易演练

一个完全离线、确定性可复现的单机股票交易模拟小游戏。界面采用中文券商工作台的信息密度，覆盖行情、个股、盘口、下单、持仓、委托、资讯、30 日挑战、复盘和存档管理。

> 模拟交易。全部行情、盘口、财务数据与新闻均为本地程序生成，不构成投资建议。

## 启动与验证

```bash
npm install
npm run dev
npm run build
npm test
npm run test:e2e
```

- 开发地址默认是 `http://127.0.0.1:4173/`
- 生产构建输出到 `dist/`
- 测试使用 Vitest + React Testing Library，不依赖网络、真实时间或真实行情接口
- 浏览器验收首次运行前执行 `npx playwright install chromium firefox webkit`
- 逐项验收结果见 [ACCEPTANCE_MATRIX.md](./ACCEPTANCE_MATRIX.md)

## 已实现市场

| 市场 | 币种 | 初始资金 | 交收 | 主要规则 |
| --- | --- | ---: | --- | --- |
| 虚构 A 股 | CNY `¥` | 1,000,000 | T+1 | 100 股主板/ST/创业板申报单位，科创板最低 200 股、1 股递增，主板/ST/创业板/科创板分别 ±10% / ±5% / ±20% / ±20% |
| 真实名称 A 股演示 | CNY `¥` | 1,000,000 | T+1 | 使用真实公司名称和代码，但价格、财务、盘口和新闻全部虚构；只使用中性演示资讯 |
| 美股风格 | USD `$` | 100,000 | T+0 | 1 股起，无每日涨跌停；可开启盘前盘后，扩展时段仅接受限价单 |

每个市场都有独立的“自由沙盒”和“30 日挑战”存档，共六个互不覆盖的槽位。切换市场或模式会暂停并保存当前仿真。

## 核心功能

- 确定性行情引擎：`hash32` + `mulberry32` 独立随机流，相同种子和操作序列产生相同价格路径。
- 当前交易日逐分钟行情，至少 260 个历史日线，最近 10 个交易日的 30 分钟 K 线。
- 分时、K 线、成交量、MA5/MA10/MA20 独立开关与 MACD 面板。
- 五档盘口、逐笔成交、限价/市价单、部分成交、撤单、收盘过期。
- A 股集合竞价按可见容量撮合：容量取买卖两侧较小值，按创建时间与订单序号消耗；竞价限价限制和 09:20–09:25、14:57–15:00 禁撤规则。
- 费用分项计算：佣金、印花税、过户费均先四舍五入到分，再合计；A 股最低佣金按订单累计只收一次。
- FIFO 持仓批次、T+1/T+0 可卖数量、冻结资金/股份、账户版本与账户世代。
- 新闻在到达模拟发布时间前不会进入界面；30 日窗口仅由独立财报日程生成 4–8 个 earnings 事件，并更新模拟基本面与估值锚定。
- 30 日挑战使用独立账户，支持评分、评级、净值/基准曲线、回撤、行业分散、交易纪律、理由覆盖率和规则化复盘。
- 本地 JSON 导出/导入、损坏存档备份、容量错误暂停、全局数据清除。
- 五步新手引导（步骤持久化、可跳过和重播）、本地帮助中心、完整术语索引与五篇短教程。
- 价格图和独立成交量图使用两个 Lightweight Charts 实例，同步逻辑范围与十字线。
- Zustand 页面切片选择器；tick、页面切换、设置修改和引导步骤变化均合并为一次状态提交。
- 1440、1024、390/375 宽度响应式布局；手机端使用底部导航，表格自身横向滚动。

## 模拟时间

- 真实世界 3 秒推进 1 个模拟分钟；支持 1、2、4、8、16 倍速。
- 虚构 A 股从 09:15 开盘集合竞价开始，11:30 后自动跳过午休，15:00 收盘。
- 美股默认 09:30–16:00；开启盘前盘后后扩展到 04:00–20:00。
- 模拟交易日历只跳过周末，不映射真实交易所节假日。
- 页面隐藏时默认暂停并保存；整个仿真只使用一个定时器。

## 存档位置

使用浏览器 `localStorage`：

```text
stock-sim:v1:settings
stock-sim:v1:cn-fic:sandbox
stock-sim:v1:cn-fic:challenge
stock-sim:v1:cn-real-demo:sandbox
stock-sim:v1:cn-real-demo:challenge
stock-sim:v1:us-sim:sandbox
stock-sim:v1:us-sim:challenge
```

保存采用临时键校验后再替换正式键。历史 K 线、30 分钟 K 线、当日分钟线和盘口逐笔属于派生数据，不直接写入每个槽位；载入后由同一种子和核心状态重建。单槽位目标小于 1.5 MB，六槽位总量目标小于 4.5 MB。

导出文件包含：

- `schemaVersion`
- `exportedAt`
- 市场、模式、种子
- 仿真状态和账户状态
- 挑战状态

导入前校验应用标识、版本、市场、模式、时间、账户金额、订单、成交、新闻和持仓结构。导入成功后会生成新的账户世代，旧页面请求不能写入新账户。

## 项目结构

```text
src/
  app/         应用组合、单一仿真定时器、错误边界
  components/  券商外壳、行情表、图表、盘口、下单、帮助、引导
  data/        三市场证券宇宙、市场规则、教程与术语
  engine/      确定性时间、随机流、历史行情、新闻、费用、撮合、挑战
  pages/       行情、自选、个股、交易、持仓、委托、资讯、挑战、设置
  store/       Zustand 状态层、原子 localStorage 存档、导入导出
  styles/      本地 CSS 设计系统与响应式规则
  test/        引擎、存档、状态和组件测试
  types/       业务数据契约
e2e/           Playwright 三引擎验收
```

## 已知限制

- 这是单机教学/演练游戏，不是交易所仿真器。集合竞价采用有限深度简化撮合，不模拟完整订单簿平衡。
- 不支持止损单、条件单、做空、融资融券、期权、碎股或自动交易机器人。
- 不处理真实公司行动、真实公告、真实交易日历和真实券商费率变化。
- 不使用真实行情、新闻、账户或远程服务；真实公司名称市场只用于界面演示。
- 引擎中的玩家成交对市场价格的长期冲击被刻意省略。
- 本应用不提供投资建议，所有财务指标和事件均不应被解释为真实信息。

## 测试加速

挑战页提供“测试加速：推进至第 30 日收盘”。它会使用当前种子在本地连续执行剩余交易日的行情与收盘结算，用于验证结算报告和评分流程。测试加速会先备份当前挑战存档，不会发送网络请求。
